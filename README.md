# my-websit-routin

一个原生 HTML / CSS / JavaScript 的小型个人网站，包含：

- 首页
- 语录页
- 项目页
- 《借过》HTML5 Canvas 单文件小游戏

## 在线访问

- 网站首页：https://gms0717.github.io/jiegou-game/
- 《借过》小游戏：https://gms0717.github.io/jiegou-game/machine.html

## 《借过》

直接打开 `machine.html` 即可游玩，无需安装依赖或启动服务器。

你是透明人，自己一步也不能走。点击路人，让他们退后，清出一条从起点到终点的路。

- 轻点：推 1 格
- 长按蓄力：推 2 / 3 / 4 格
- 双击空地：跺脚弹开周围的人（每关 3 次）
- 5 个教学关 + 机关试验场
- 支持鼠标与触摸
- 进度、星级、成就保存在浏览器 localStorage

游戏逻辑、关卡数据、渲染、音效都在 `machine.html` 内，方便直接分享或单独部署。

## 本地预览

直接双击 `index.html` 或 `machine.html`，或使用任意静态文件服务器。
